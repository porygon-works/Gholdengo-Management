## 段階1：タブと入力の画面（出金・入金）

**作るもの:** 下のタブを「ホーム・明細・入力・見通し・計画」にし、設定をメニューへ移す。入力の画面に「出金｜入金｜残高｜計画」の切り替えを置き、出金と入金を入れられるようにする（保存の前の比べつき）。保存したあと、いま入れたものを下に数件出す。

**確かめ方（本人）:**
1. 真ん中の「入力」を押すと、出金の欄が開いている。
2. 出金で、払い方をカードにして保存すると明細の出金に「三井」と出る。口座・PayPay・現金も同じように入る。
3. 入金で、区分を賞与にして保存すると、設定の給与・賞与の一覧に出る。
4. 設定は右上のメニューから開ける。

**完成の条件:** 上の4つ。予定か確定かの最初の値が日付で変わる（先の日付なら予定）。

## 段階2：入力の画面（残高・計画）とほかの入力口

**作るもの:** 残高（口座の残高・借入残高・カードの請求額）と計画（積立追加・賞与配分・取崩）を入力の画面に置く。ホームの支出入力をなくす。明細の「新規入力」・設定の賞与の入力・メニューの残高は、入力の画面を開く。

**確かめ方（本人）:**
1. 入力 → 残高で口座の残高を入れると、ホームの口座残高が変わる。
2. 入力 → 残高で借入残高を入れると、計画の返済先の額が変わる。
3. 入力 → 計画で積立追加をすると、その貯蓄計画の額が増える。
4. ホームに入力の欄がない。

**完成の条件:** 上の4つ。入力口が入力の画面だけになっている。

## 段階3：明細を出金・入金で分ける

**作るもの:** 明細の切り替えを「出金｜入金」にする。出金はカード・口座・PayPay・現金をまとめて並べ、行に払い方を出し、払い方で絞れる。クレカの引き落としの行は出さない。

**確かめ方（本人）:**
1. 明細 → 出金に、カードと口座の出金が一緒に並び、払い方が分かる。
2. 払い方の絞り込みで「三井」だけにできる。
3. 明細 → 入金に、給与・賞与などが並ぶ。
4. 行を押すと、いままでどおり直せる・消せる。

**完成の条件:** 上の4つ。費目別の合計がいまと同じ。

## 段階4：見直しと仕様書

**作るもの:** スマホの幅と暗い画面で全部の入力を操作して見直す。`docs/SPEC.md` の画面の章を直す。

**完成の条件:** 型チェック・テスト・ビルドが通る。仕様書と設計書が画面と合っている。
